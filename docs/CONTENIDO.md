## Registro de recuerdos

Para cada episodio, basta con aportar:

```text
Título interno:
Fecha o año (exacto / aproximado / desconocido):
Qué pasó realmente, en dos o tres frases:
Quién lo cuenta:
Quién aparece, según vosotros:
Pruebas vinculadas (LC-xxx o nombres de archivo):
Frase o broma literal que queréis usar:
Visibilidad (online / solo offline / secreto de juego):
```

Para las fichas: apodo si existe, un «cargo» absurdo explícitamente ficticio, frase propia y hasta tres recuerdos confirmados. Para Kili: fecha de boda, vídeo/carta real de los otros tres y qué sorpresa debe quedar reservada.

No hay aventuras, ciudades, fechas de viajes ni biografías inventadas. La fecha del nombre de una captura no se usará como fecha del recuerdo. Las variantes visuales pueden agruparse sin descartar ningún original.
